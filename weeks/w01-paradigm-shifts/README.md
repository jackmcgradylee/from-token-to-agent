# W1 — Three Paradigm Shifts

## What this week is about

How did learning signals evolve from explicit human labels toward signals generated by data, verifiers, environments, and eventually the model itself? This week is about understanding the *signal ladder* before touching any model code.

## Status

In Progress (smoke only).

## Implemented so far

- `src/token_to_agent/tokenizer/bpe.py` — minimal byte-level BPE, ~280 LOC, no external tokenizer-training library used.
  - Byte-level, with whitespace as its own token (so spaces round-trip through encode/decode).
  - 4 special tokens (`<pad>` / `<bos>` / `<eos>` / `<unk>`) + 256 byte tokens + merge table.
  - I/O: `BPETokenizer.train(texts, vocab_size)` / `.encode(text)` / `.decode(ids)` / `.save(path)` / `.load(path)`.
- `tests/tokenizer/test_bpe.py` — 5 tests, all passing: train, round-trip, special tokens, save/load, byte-level coverage (every byte 0..255 round-trips).
